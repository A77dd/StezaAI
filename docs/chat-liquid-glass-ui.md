# Чат «Чёрный ящик»: liquid-glass UI — передача работы

Дата обновления: 2026-09-29. Ветка: `codex/liquid-glass-chat-ui`
(база — `origin/telegram_webapp`).

## Что сделано (обзор)

Экран чата переработан вокруг концепции «чёрного ящика»: в центре сцены — стеклянная
капля (WebGL2-метаболлы), за ней — текст и кнопка «+», которые капля честно преломляет.
Весь хром приложения (шапка, поле ввода, нижняя навигация) переведён в единый стиль
liquid glass. Сцена и хром рассчитаны **только на мобильные** пропорции.

Ключевые механики:

1. **WebGL-сцена на весь экран** — канвас вынесен порталом в `body`, `position: fixed`,
   под всем приложением; хром сделан прозрачным. За каплей рисуется 2D-сцена
   (точечный паттерн, виньетка, текст, «+») и отдаётся шейдеру текстурой — поэтому
   стекло преломляет и точки, и текст, и «+».
2. **Два состояния капли** — пресеты `rest` / `thinking`, плавное перетекание по фазе
   чата (`idle|result → rest`, `processing → thinking`). Угол вращения и фаза слияния
   **интегрируются по кадрам** (`rotationAngle += dt * speed`), а не считаются как
   `t * speed` — иначе смена скорости телепортирует фазу (это была причина «тряски»).
3. **«Дыхание» в размышлении** — орбита плавно отклоняется до +50% и обратно,
   период 4 с, амплитуда нарастает тем же переходом состояний.
4. **Текст со stagger-анимацией** (референс transitions.dev):
   - вход построчно: fade + сдвиг 12px + blur 3px, 500 мс, задержка 40 мс на строку,
     кривая cubic-bezier(0.22, 1, 0.36, 1) (честный численный солвер без CSS);
   - уход — тихий fade 200 мс на месте, без обратного reveal;
   - конечные значения фиксируются точно — «призраков» текста в текстуре нет.
5. **Шиммер «Думаю...»** — приглушённая база + бегущая белая полоса (2 с, linear),
   градиент клипится по глифам; работает всё размышление.
6. **Кнопка «+» нарисована в сцене** под текстом (42px от центра), стекло её
   преломляет; клик ловится по hit-test области (+20px допуск) на `pointerdown`.
7. **Формат сцены фиксирован тёмным.** Тема больше не переключается сама по фазам
   (это убрано как нежелательное). Светлый формат (`format: 'light'`: белый фон,
   серые точки, tint 0, edge shadow 0.55 в любом состоянии) доступен вручную через
   отладочную панель.
8. **Виньетка** — затемнение (тёмный формат) / забеление (светлый) по краям:
   верх/низ сильнее, бока мягче, цвет следует за форматом.
9. **Liquid glass хром** (референс — CodePen «Liquid glass» Den Dionigi):
   - общие переменные `--glass-panel-shadow` / `--glass-button-shadow`,
     рефлексы переключаются темой (`--glass-reflex-light/dark`);
   - `backdrop-filter: blur(8px) url(#nav-switcher|nav-toggle) saturate(150%)` —
     SVG displacement-фильтр (карта смещений `displacement-map.txt`, ?raw импорт);
   - применено к: нижним пилюлям, шапке, полю ввода, кнопке отправки, кнопке
     уведомлений.
10. **Нижняя навигация**: в большой пилюле 3 таба (кнопка «+» убрана), пилюля
    тянется на всю ширину между отступами; под активным табом скользит «пальчик» —
    треть ширины пилюли, перенос 400 мс cubic-bezier(1,0,0.4,1) + пружинное
    растяжение 440 мс с transform-origin по направлению движения. Чат-кнопка —
    стекло без зелёной заливки, внутри `ThinkingOrb` (`thinking-orbs`, state
    `composing`, size 32) — отцентрован, отступы по 12px.
11. **Ввод**: только кнопка отправки (активная при непустом поле / неактивная).
    Микрофон, голосовой ввод и оверлей записи удалены (голос вырезан до решения
    продукта; `voice-glow` в ветке не используется).
12. **Контроль непрерывной анимации**: render loop останавливается в скрытой вкладке
    и когда canvas не пересекает viewport. При `prefers-reduced-motion: reduce`
    состояние обновляется одним статичным кадром без вращения, дыхания, шиммера и
    stagger-переходов. Правила покрыты unit-тестами.

## Пресеты состояний (зафиксировано владельцем)

Общее: `metaballThreshold 0.5`, `magnetism 1.0`, `dropElongation 1.10` (макс. 1.10),
`glossiness 120`, `tintOpacity 0.06`, `glowIntensity 1`, `blur 0`, `mouseMass 0`,
ripple выключен.

| Параметр          | rest   | thinking |
|-------------------|--------|----------|
| orbitRadius       | 30     | 116      |
| rotationSpeed     | 0.10   | 0.60     |
| mergePhase        | 0.12   | 0.23     |
| dropRadius        | 75     | 70       |
| refraction        | 0.16   | 0.11     |
| dispersion        | 0.03   | 0.04     |
| specular          | 0.4    | 0.8      |
| fresnelDark       | 0.25   | 1.0      |
| rippleIntensity   | 0      | 0.6      |

Глобальные `PARAMS`: точки `19 / 1 / 0.18` (адаптив: плотность нормирована к ширине
390px, кламп 0.85–1.25), виньетка `1.0 / 0.5` (верх-низ) и `1.0 / 0.5` (бока),
`blobScale 0.7` (масштабирует и геометрию, и силу преломления — иначе маленькая
капля «размазывает» текст), формат `dark`.

Тайминги: размышление 4.4 с; переходы состояний ~1.2 с (`1 - exp(-dt*2.5)`),
цвета формата ~1.5–2 с (`1 - exp(-dt*2)`).

## Известные ограничения / что дальше

- Сцена мобильная; на десктопной ширине выглядит крупно — при необходимости
  включайте `blobScale` в отладке и подбирайте адаптив аналогично точкам.
- `voice-glow` рассмотрен и сознательно вырезан (владелец): свечение/голос вернутся
  отдельным решением.
- Отладочная панель меняет только runtime-значения; финальные значения после
  подгонки нужно вписывать в `PARAMS` / `STATE_PRESETS` (перезагрузка сбрасывает).
- ripple-клик по фону выключен пресетами; механика осталась в шейдере и включается
  флагом `enableClickRipple` + `rippleIntensity`.
